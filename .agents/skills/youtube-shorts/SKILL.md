# YouTube Shorts Creator & Planner Skill

이 스킬은 깃허브에서 검증된 고유지율(High-Retention) 숏폼 프레임워크와 Remotion/HTML5 기반의 프로그래밍 방식 비디오 생성 패턴을 결합하여, 60초 유튜브 쇼츠의 기획부터 대본 작성, 시각 연출, 인터랙티브 프리뷰까지 자동화합니다.

## 핵심 제작 파이프라인

1. **기획 구체화 (7대 체크리스트 적용)**
   - 주제 좁히기, 5060/직장인 등 구체적 타겟 페르소나 설정, 60초 세로형(9:16) 규격 준수
2. **시청 지속시간 극대화 대본 작성 (60초 큐시트)**
   - `0~3초` 스크롤 정지 후킹 (문제 제기형 vs 결과 증명형 2안)
   - `4~15초` 타겟 고민/답답함 극대 공감
   - `16~35초` 1초 핵심 해결책 시연 (자판 마이크 터치 등 구체적 행동 유도)
   - `36~45초` 반전 인사이트 (인식률 99%, 속삭여도 인식 등)
   - `46~58초` 댓글 참여 유도 및 다음 편 기대를 부르는 CTA
3. **인터랙티브 9:16 모바일 프리뷰어 생성 (`shorts_preview.html`)**
   - Web Speech API 기반 한국어 TTS 음성 자동 싱크
   - 구간별 키네틱 타이포그래피 및 시각 연출 애니메이션
   - 실제 유튜브 쇼츠 UI(좋아요, 댓글, 공유, 음원 아이콘) 시뮬레이션
4. **알고리즘 노출 SEO & A/B 테스트 패키지**
   - 32자 이내 모바일 최적화 제목 3안
   - 검색 상위 노출 해시태그 8개
   - 클릭률(CTR) 극대화 썸네일 빅텍스트 2안 및 AI 이미지 프롬프트
